# Team architecture package

Use [the standalone handbook](team-handbook/README.md) as the distribution package. It explains responsibilities, data rules, shared records, six work packages and an integration owner for an independent build.

The handout does not require access to a reference implementation. It intentionally omits source filenames, class names, branch history and prior implementation/test claims. Architectural behavior and approved analytical semantics are the build requirements.

Share the docs/team-handbook/ folder itself. Historical repository decisions and internal review archives are outside this handout. The overview and detailed architecture documents use the same responsibility-based vocabulary.
